# 📈 MarketPulse: Next-Day Stock Price Forecaster

## 📝 Problem Statement
Stock market data is highly volatile and complex, making it a challenging task to predict future trends. Accurately forecasting stock prices is crucial for data-driven investment strategies.

## 🎯 Goal
The objective of this project is to utilize historical stock market data (Open, High, Low, Volume) retrieved via `yfinance` to train a regression model (Linear Regression or Random Forest) that predicts the next day's closing price.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Source:** `yfinance`
* **Data Manipulation & Analysis:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn (Linear Regression, Random Forest)
